# 07_Codigo_Aula — Aula 03 (React)

## Objetivo
Construir o primeiro projeto React (Vite) do TechFood: Header, CardPrato com
props e a lista do cardápio via `.map()`.

## Como rodar
Dentro de `exemplos/techfood-react` ou `exercicios/techfood-react`:
```
npm install
npm run dev
```
Abra o endereço mostrado (ex: http://localhost:5173).

## Estrutura
- `exemplos/techfood-react/` — solução completa (referência do professor / consulta).
- `exercicios/techfood-react/` — base pronta + comentários `TODO` (ponto de partida do aluno).

## Tópicos
Componentes · JSX · props · listas com `.map()` e `key` · HTML semântico.
